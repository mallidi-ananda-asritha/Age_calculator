Age Calculator

Project Overview:

The Age Calculator is a simple and easy Python application that calculates a person's exact age based on their date of birth.

It displays the age in years, months, and days. The application validates user input and handles invalid dates and future dates.

Objectives

Calculate exact age in years, months, and days.

Handle leap years and different month lengths.

Validate date of birth entered by the user.

Prevent future dates.

Provide a simple command-line interface.

Technologies Used

Programming Language: Python

Module: datetime

Module: calendar

Interface: Command Line Interface (CLI)
Features

Calculates exact age.

Accepts date of birth in DD-MM-YYYY format.

Validates date entries.

Rejects future dates.

Handles leap years.

Displays age in years, months, and days.

Installation and Execution

Step 1: Install Python

Download and install Python from:
https://www.python.org/downloads/

Step 2: Clone or Download the Project

Download the project files to your computer.

Step 3: Open the Project

Open the project folder in Visual Studio Code.

Step 4: Run the Application

Open the terminal and execute:

python age_calculator.py

Step 5: Enter Date of Birth

Enter your date of birth in the following format:

DD-MM-YYYY

The application will display your exact age.
